# The House Barbershop — website

Complete responsive website: HTML, CSS, JavaScript, photographs and fonts.

## Open locally
Open index.html in your browser. No installation or build step is required.
The service list is embedded in the page so that the price tabs work offline.
Booksy reservations, Instagram and Google Maps require an internet connection.

## Publish on your hosting
Upload the contents of this folder to the hosting public directory.
The website is static and requires no database or backend.

## Files
- index.html: page content and embedded service data
- style.css: desktop and mobile layouts
- app.js: menu, service tabs, gallery and privacy dialog
- services.json: reference copy of the service data
- assets/: original salon logo, optimized photographs and local fonts

Prices, business details and photos: salon Booksy profile, 6 November 2026.
Booksy is the source of truth for current prices and availability.
